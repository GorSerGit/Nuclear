# Материалы демонстрации

- **Скринкаст работы интерфейса и сквозного трекинга:**
  https://drive.google.com/drive/folders/1wetiH9qStdNXzojK7xymWDFdKbYeugFR
- **Скриншоты интерфейса на предоставленном видео** — в [Отчёт.pdf](../../Отчёт.pdf): отслеживание при перекрытии (рис. 1–3),
  потеря детекции (рис. 4–6), поиск и аналитика (рис. 7–8), полный цикл работы — загрузка, калибровка, зоны исключения,
  план, поиск, контроль трека (рис. 9–14).
- **Готовый просмотр всей записи** — архив `Nuclear_ui_office.zip` в
  [Release v1.0](https://github.com/GorSerGit/Nuclear/releases/tag/v1.0): распакуйте в папку репозитория,
  запустите `!start.bat` и выберите «Результат → Вся запись». Там синхронное видео 5 камер, силуэты с ID трека,
  список треков, шкала времени, план с путём и вкладка «Аналитика».
- **Входные видео** — `Nuclear_data_weights.zip` в том же Release (`data/office/camera_new_1…5.mkv`).

Видео в Git не кладутся из-за размера (файлы до 305 МБ), поэтому они вынесены в Release.
