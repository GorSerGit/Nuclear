# Артефакты тестирования

Результат полного прогона на предоставленном видео (5 камер, 20 минут). **Уникальных сквозных треков: 108.**

| Файл | Что внутри |
| --- | --- |
| [tracks.csv](tracks.csv) | все треки: `track_id`, начало и конец (`start`, `end`, секунды `t0_s`, `t1_s`), длительность, камеры, интервалы на каждой камере, причины начала и конца, человек P. Разделитель `;` |
| [tracks.json](tracks.json) | то же в JSON |
| [persons.csv](persons.csv) | люди: треки каждого человека и промежутки, когда его не видела ни одна камера |
| [rejected_tracks.csv](rejected_tracks.csv) | что не вошло в счёт (дубли, фантомы, шум) и почему |
| [report.md](report.md) | сводка: таблица треков и условия съёмки |

Полные данные прогона (наблюдения, кропы, база SQLite) — архив `Nuclear_results.zip` в
[Release v1.0](https://github.com/GorSerGit/Nuclear/releases/tag/v1.0).
