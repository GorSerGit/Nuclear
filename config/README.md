# Настройки

Настройки лежат в папке [`../configs/`](../configs) (код ссылается на неё, поэтому она не переименована).
Секретов и ключей решение не использует, `.env` не нужен.

| Файл | Что задаёт |
| --- | --- |
| [`configs/config.yaml`](../configs/config.yaml) | общие параметры: детектор, трекер, нарезка на треклеты, склейка, правила сквозных треков (`end_gap_s: 2.0`) |
| [`configs/office/cam1–5.json`](../configs/office) | паспорта камер: видео, fps, сдвиг часов, зоны исключения (экраны, зеркала), объектив `K`, гомография `H`, точки привязки |
| [`configs/office/site.json`](../configs/office/site.json) | план этажа: картинка, масштаб (px/м), положение камер |
| [`configs/office/overrides.yaml`](../configs/office/overrides.yaml) | пороги для офиса поверх `config.yaml`: Re-ID PersonViT, запасы на передачу между камерами, сборка людей |
