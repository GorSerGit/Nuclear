# Ограничения решения

## Поддерживаемые условия

- Стационарные синхронные камеры, у каждой есть привязка к плану этажа (гомография). Камера без привязки обрабатывается,
  но с другими не связывается.
- Люди стоят и ходят по полу одного этажа; точка опоры видна хотя бы частично.
- Широкоугольные объективы до ~120° (выпрямление по равноудалённой модели).
- Windows 10/11 и Python 3.13; GPU NVIDIA желателен. Проверено на RTX 4060, 4080, 3070 Ti и RTX PRO 6000 (Colab).

## Известные ограничения

- **Точность плана на краях кадра** 0.4–1.1 м: у края «рыбьего глаза» и у лестницы два вида одного человека могут
  разойтись на плане, и человек разрывается на два трека.
- **Похоже одетые люди** (тёмная одежда, синий неон на лестнице cam2) близки по внешности; в записи один P-номер (P8)
  объединяет нескольких людей с лестницы. Счёт треков от этого не меняется, страдает только сборка в людей.
- **Долгое полное перекрытие толпой** выглядит как выход из всех камер — трек завершится и начнётся новый.
- **Неразмеченные выходы.** Если человек сел посреди комнаты и через несколько секунд ушёл в проход без зоны выхода,
  трек может ошибочно продолжиться через сшивку пропуска детекции (до 8 с).
- **Статичные ложные детекции** (плакат, отражения) отсекаются зонами исключения и правилами «фантом»/«призрак»;
  новую такую помеху нужно разметить зоной.
- **Поиск по описанию** понимает цвета верха и низа, время и камеру, но не фасон одежды (юбка, платье) и мелкие детали.
- Пороги подобраны на EPFL и этой записи; для другого помещения их нужно проверить.

## Что не входит в текущую версию

- Обработка потока в реальном времени: сейчас обрабатываются записанные файлы (≈ 20 мин на 20-минутную запись на RTX PRO 6000).
- Идентификация личности и распознавание лиц.
- Склейка камер без привязки к плану.
- Полноценная поддержка Linux: есть скрипт `start.sh`, но основная и проверенная платформа — Windows.

## Риски демонстрации

- Первый запуск `!start.bat` ставит Python и зависимости (несколько гигабайт, нужен интернет).
- Без архивов из Release v1.0 нет видео, весов и готового результата — интерфейс будет пустым.
- Полная обработка без GPU занимает часы; для демонстрации используйте готовый результат «Вся запись».

## Дальнейшее развитие

- Предсказание движения (фильтр Калмана) в слепых зонах между камерами.
- Дообучение Re-ID на офисных кропах и учёт освещения каждой камеры.
- Автоматическая разметка зон выхода (двери, лестницы) по траекториям.
- Работа с потоком (RTSP) и инкрементальная склейка.
- Текстово-визуальная модель для поиска по свободному описанию (фасоны, аксессуары).
