# Методика и результаты тестирования

## Предоставленное видео (офис NtechLab)

**Данные:** 5 камер, 20 минут (0:00–20:04), 2592×1944, 20–25 кадров/с; сдвиги часов камер 0–4.2 с учтены в паспортах.

**Методика:** полный прогон `python -m mtmc run --passports "configs/office/cam*.json" --site configs/office/site.json`
с настройками из `configs/config.yaml` и `configs/office/overrides.yaml`. Результат проверялся вручную в интерфейсе:
переходы между камерами, перекрытия, потеря детекции, выходы на лестницу; спорные случаи записаны в [DECISIONS.md](../DECISIONS.md).

| Показатель | Значение |
| --- | --- |
| Уникальных сквозных треков | **108** |
| Треков через 2 и более камер | 69 |
| Треков через все 5 камер | 9 |
| Медианная длина трека | 13.6 с |
| Людей (сборка треков по внешности, подсказка) | 34 |
| Точность привязки к плану | 0.4–1.1 м |

Списки: [tracks.csv](../artifacts/test-results/tracks.csv) — ID, начало, конец, камеры и интервалы на каждой камере;
[persons.csv](../artifacts/test-results/persons.csv) — треки каждого человека;
[rejected_tracks.csv](../artifacts/test-results/rejected_tracks.csv) — что не вошло в счёт и почему;
[report.md](../artifacts/test-results/report.md) — сводка и условия съёмки.

**Найденные ошибки:** ложный трек от плаката на стене cam1 (P12) — добавлена зона исключения; на лестнице cam2 синий неон
сближает внешность разных людей, и номер P8 объединяет нескольких человек (решение оставить 34 человека описано в DECISIONS.md).
